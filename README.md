# TechPulse — Electronics & Tech Gear E-Commerce Platform

**TechPulse** is a modern, responsive e-commerce front-end website designed for developers, creators, and technology enthusiasts.

The project presents a fictional tech store featuring products such as laptops, smartphones, and audio equipment, with a modern dark-themed interface and interactive JavaScript components.

---

## Features

- **Responsive Design**  
  Designed to provide a consistent experience across desktop and mobile screen sizes.

- **Modern Dark UI**  
  Clean dark-themed interface with custom accents and modern visual elements.

- **Product Catalog**  
  Browse technology products with categories, specifications, and pricing information.

- **Interactive Navigation**  
  Multiple pages connected through a consistent navigation system.

- **Sign-In Interface**  
  Front-end sign-in page with User/Admin role selection.

- **Interactive Modals**  
  JavaScript-powered popups for user interactions and sign-in feedback.

- **Multiple Website Sections**  
  Includes Home, Products, About, Contact, and Sign-In pages.

## Getting Started

### Prerequisites

No special backend environment is required.

You only need:

- A modern web browser
- Visual Studio Code or another code editor
- **Live Server** extension (recommended)

### Run Locally

1. Clone the repository:

```bash
git clone https://github.com/your-username/techpulse.git
```

2. Open the project folder:

```bash
cd techpulse
```

3. Open `index.html` using **Live Server** or directly in your browser.
