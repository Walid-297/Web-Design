# Modern Community Landing Page

A modern, responsive **community landing page** built with **HTML5, Tailwind CSS, and pure CSS**.

This project focuses on practicing modern frontend development fundamentals, including responsive layouts, component-like page organization, CSS transitions, hover interactions, and modern UI design techniques.

---

# Overview

The project is a single-page community website featuring a modern navigation header, hero section, and initiatives showcase.

The interface was designed with a focus on:

- Responsive layouts
- Modern visual design
- Clean page structure
- CSS-based interactions
- Reusable Tailwind utility classes
- Smooth transitions and animations

The project was primarily built as a practical exercise to strengthen my understanding of **HTML, CSS, Tailwind CSS, responsive web design, and frontend UI development**.

---

# Why I Built This

This project was created as part of my frontend development learning journey.

Rather than focusing only on making a page that "looks good", I used the project to practice how real interfaces are structured and styled.

Through this project, I explored:

- How to structure a responsive webpage
- How modern navigation headers are designed
- How Tailwind CSS utilities can be combined to create layouts
- How CSS transitions and pseudo-elements create interactive effects

The goal was to turn frontend concepts from theoretical knowledge into practical implementation.

# Features

- **Responsive Layout**  
  Adapts the interface to different screen sizes.

- **Glassmorphism Header**  
  Sticky navigation with translucent backgrounds and backdrop blur effects.

- **CSS-Based Navigation Interactions**  
  Dropdown and hover interactions implemented using CSS rather than JavaScript.

- **Hero Section**  
  Full-screen introductory section with responsive typography and visual overlays.

- **Initiatives Showcase**  
  Responsive card-based layout presenting community initiatives.

- **Image Hover Effects**  
  Smooth image zoom and transition effects using CSS.

- **Custom Theme**  
  Tailwind configuration with a custom color palette for consistent visual styling.

- **Smooth Transitions**  
  CSS transitions and transforms used throughout the interface to improve interaction feedback.

# Design Highlights

### Glassmorphism Navigation

The navigation header uses:

- Transparency
- Backdrop blur
- Sticky positioning
- Subtle borders
- CSS transitions

to create a modern glass-style interface.

### Responsive Layout

The page uses Tailwind's responsive utilities to adapt:

- Typography
- Navigation
- Hero content
- Initiative cards
- Spacing
- Grid layouts

across different screen sizes.

### CSS Interactions

Several interactions are implemented without JavaScript, using:

- `:hover`
- Pseudo-elements
- `transform`
- `transition`
- CSS positioning

This helped reinforce how much interactivity can be achieved using CSS alone.

# Getting Started

## Prerequisites

No build tools are required.

You only need:

- A modern web browser
- VS Code or another code editor
- Internet connection for the Tailwind CDN and Google Fonts

## Run the Project

Clone the repository:

```bash
git clone https://github.com/your-username/your-repository-name.git
```

Navigate into the project:

```bash
cd your-repository-name
```

Then open:

```text
index.html
```

You can also use **VS Code Live Server** for a better development experience.
