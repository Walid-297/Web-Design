# BOTOL — Premium Hydration E-Commerce Landing Page

A modern, responsive **e-commerce landing page for a premium water bottle brand**, implemented from a provided **Figma design** using HTML5 and CSS3.

The project focuses on translating a visual UI design into a functional web interface while practicing responsive layouts, modern CSS techniques, interactive components, and design-to-code implementation.

---

# Overview

BOTOL is a product-focused landing page designed around a premium hydration brand.

The interface includes multiple sections commonly found in modern e-commerce websites, including:

- Hero section
- Product showcase
- About Us section
- FAQ section
- Contact form
- Footer

The project was implemented based on a Figma design, with the goal of reproducing the visual structure, spacing, typography, colors, and overall user interface as closely as possible.

---

# Why I Built This

This project was created as a practical exercise in **Frontend Development and UI Implementation**.

One of the main goals was to practice converting a visual design into an actual webpage.

Instead of only designing the interface, I focused on understanding how the design translates into:

- HTML structure

- Responsive behavior
- Typography systems
- Spacing and positioning
- Interactive components
- Reusable styling patterns

This project helped me understand the gap between **design specifications and real-world implementation**, which is an important skill when working with UI/UX designs created in tools such as Figma.

# Getting Started

## Prerequisites

No build tools are required.

You only need:

- A modern web browser
- VS Code or another code editor
- VS Code Live Server (recommended)

---

## Run the Project

Clone the repository:

```bash
git clone https://github.com/your-username/BOTOL.git
```

Navigate into the project:

```bash
cd BOTOL
```

Make sure the required image assets are located in the expected project directory.

Then open:

```text
index.html
```

You can also run the project using **VS Code Live Server**.
